# تقویم سه‌گانه (شمسی • قمری • میلادی) — PWA

اپ Progressive Web App کامل برای نمایش همزمان سه تقویم.

## ویژگی‌ها

- تقویم ماهانه شمسی با جابجایی ماه
- نمایش **روز قمری** (اعداد فارسی) و **روز میلادی** (اعداد انگلیسی) زیر هر روز شمسی
- کلیک روی هر روز → نمایش تاریخ سه‌گانه همان روز در بالای صفحه
- دکمه «برو به امروز» برای بازگشت به حالت فعلی
- تنظیمات رؤیت هلال (جابجایی روز قمری + طول ماه‌های ۲۹/۳۰ روزه)
- ذخیره تنظیمات در localStorage
- کار کامل آفلاین
- قابل نصب روی گوشی

## نصب روی Samsung Galaxy S22

1. فایل‌ها را روی هاست HTTPS آپلود کنید
2. با Chrome باز کنید → منوی ⋮ → **Install app**

یا با Samsung Internet: Add page to → Home screen
